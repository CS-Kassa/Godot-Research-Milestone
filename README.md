# Target Rush — Godot Research Milestone

## Project Overview
Target Rush is an interactive 2D target-clicking game developed using Godot 4 and GDScript.

Players select a difficulty level and attempt to click as many randomly positioned targets as possible before the 20-second timer expires.

## Features
- Three difficulty levels: Easy, Medium, and Hard
- Randomly positioned targets
- Score tracking
- Countdown timer
- Game Over screen with final score
- Replay functionality

## Technologies
- Godot 4
- GDScript
- Git and GitHub

## Research Findings
Godot was selected because it is free, open-source, and includes tools for building 2D games. Compared with Unity and Unreal Engine, Godot is lightweight and approachable for a small 2D project.

I learned how to create scenes, work with nodes, use GDScript, connect signals, and implement timers.

Godot also provides an Asset Library for finding extensions and reusable assets. For this sample project, I used built-in Godot functionality without external dependencies.

## How to Run
1. Download or clone this repository.
2. Open Godot 4.
3. Import the `project.godot` file.
4. Open `main.tscn`.
5. Press F6 to run the scene.
